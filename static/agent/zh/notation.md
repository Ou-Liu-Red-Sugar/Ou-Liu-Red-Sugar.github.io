# 符号与单位

这份表统一笔记中的常用记号. 数学期望写作 $\mathbb{E}$；金额与数量的量级使用 K、M、B.

## 概率与统计

| 记号 | 含义 | 使用约定 |
|---|---|---|
| $\mathbb{E}[X]$ | 数学期望 | 期望运算统一采用黑板粗体. |
| $\mathbb{E}[X\mid\mathcal{G}]$ | 条件期望 | $\mathcal{G}$ 是给定的信息. |
| $\mathbb{E}_P[X],\ \mathbb{E}_Q[X]$ | 不同测度下的期望 | P 通常为现实测度，Q 为所指定的定价测度. |
| $\widehat{\mathbb{E}}[X]$ | 期望的估计值 | 帽号表示由样本或数值方法得到的估计. |
| $P(A),\ Q(A)$ | 事件的概率 | 写明采用的测度. |
| $\operatorname{Var}(X),\ \operatorname{Cov}(X,Y)$ | 方差、协方差 | 运算符使用正体. |
| $\rho_{XY}$ | 相关系数 | 同时明确样本范围或分布. |
| $\mathbf{1}_A$ | 事件 A 的示性函数 | 事件发生时为 1，否则为 0. |
| $\Omega,\ \mathcal{F},\ (\mathcal{F}_t)$ | 样本空间、事件族与信息流 | 信息流按时间递增. |
| $X_t,\ W_t$ | 随机过程与布朗运动 | 时间范围、测度和过程假设在正文给出. |
| $\mu,\ \sigma,\ \Sigma$ | 均值或漂移、波动率、协方差矩阵 | 注明时间尺度；具体含义随模型定义. |

## 市场、合约与组合

| 记号 | 含义 | 使用约定 |
|---|---|---|
| $t,\ T,\ \Delta t$ | 当前时点、终止时点、时间间隔 | 利率与时间单位相配. |
| $S_t$ | 标的或现货价格 | 注明币种和每单位标的. |
| $F_{t,T}$ | 远期或期货报价 | 产品类型与到期日在正文中明确. |
| $K,\ C_t,\ P_t$ | 行权价、看涨期权价格、看跌期权价格 | 注明合约单位与乘数；P 的含义由上下文确定. |
| $V_t,\ B_t$ | 合约或组合价值、现金账户价值 | 写清计价单位及现金账户的累积规则. |
| $R,\ r$ | 回报或利率 | 简单回报、对数回报与年化利率在首次使用时区分. |
| $w_i,\ q_i,\ N$ | 组合权重、持有数量、名义本金或样本量 | 每篇按实际用途定义 N，并列出合约乘数. |
| $A=L+E$ | 资产＝负债＋权益 | 此处 E 是权益，金额口径和时点须一致. |

## 金额与数量

| 记号 | 含义 | 使用约定 |
|---|---|---|
| K | $10^3$ | 例如 250 K 股 = 250,000 股. |
| M | $10^6$ | 例如 4,105 M 美元；表头写“单位：USD M”. |
| B | $10^9$ | 例如 12.5 B 美元 = 12,500 M 美元. |
| USD / CNY / EUR | 美元 / 人民币 / 欧元 | 币种与量级分别标注；每股金额用 USD/股等形式. |
| bp | $10^{-4}=0.01\%$ | 一个基点；利率差与收益率差可用 bp. |

展示的小数最多保留三位，省略末尾多余的零；计算继续使用原始精度. 比例与百分数分别写清，例如 $0.125=12.5\%$.

运算符保持统一，变量在首次使用时定义. 局部语境可以复用字母：例如资产负债表中的 $E$ 表示权益，状态空间中的 $E$ 表示集合；它们与数学期望 $\mathbb{E}$ 区分. 行权价 $K$、现金账户 $B_t$ 使用数学斜体，量级 K、M、B 使用普通文本. 原始资料中的记号在引用时说明与本表的对应关系.
