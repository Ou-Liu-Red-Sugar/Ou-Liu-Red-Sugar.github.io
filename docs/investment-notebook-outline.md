## 定位与范围

### 定位

这套笔记以股票和基本面为主线。已有十篇完成投资对象、市场交易、持有回报和实际组合；随后重建业务、财报、情景与条件定价，训练 Agent 的材料语义、经营推演和判断，再深化资本取舍与持续配置。

### 读者与学习目标

面向愿意认真理解投资的普通读者。金融基础在使用处展开，不要求先学测度论、随机分析、复杂估值计算或编程。已有相应知识的读者可通过主题导航直接进入需要的部分。

### 讲解深度

每篇承担相对已写正文的新增职责，按实际理解问题保留定义、实例和必要推导。

股票和业务研究构成主线；金融条件、基金、债券、实物资产和合约工具在相应问题出现时补读。

B03 已承担实际组合、保证金和对冲入口。后续组合篇深化共同经营情景、联合概率和持续采用，复用已有机制与计算。

Agent 负责理解材料、识别传导、比较解释、形成预测和取舍；程序帮助整理和计算，前向证据用于检验并定向培养判断。

公司估值按业务状态、普通股所得、适配参照和 Risk-Reward 组织，不编排 DCF/WACC 估值训练；资金时间、实际借款成本、债券和合约计算保留各自用途。

## 写作节奏

每天计划推进 5 篇词条，逐篇完成后再进入下一篇。

先按本大纲定位本篇题目、学习理由、主要先修和详略，再沿 chinese-writing 的实际第0版、第1版、修订与定稿流程推进。本大纲不是任何词条的草图，也不预先宣布正文阶段完成。

同一时刻推进一篇词条。每天约5篇是写作目标，按实际复杂度、审读和返修调整；以完成定稿为计数，不以创建文件或提交草图充数。

实例和交互在第0版就安排用途。最终页面保留不用操作也能读懂的默认图形和文字，交互用于比较条件、解释过程或展开证据。

同一份知识按主要职责归入一个主题；其他主题通过链接使用。公司案例随问题选择，避免让现成数据反过来决定题意和开头。

词条逐篇完成。用户指定的篇目可以先生成只含大纲的占位页，并在导航中标为“大纲”；已完成正文再加入正式源、搜索和 Agent 导出。

## 资料采用原则

金融市场基础的具名参考是 [现有 TeX 讲义](F:/Investing/workspace/learn/stochastic-processes-financial-markets/tex/main.tex)，采用其中与新题目相符的解释和实例；原章节顺序及进阶推导不规定新大纲。

Agent 研究和配置参考 [Investing-v3](F:/Investing-v3/README.md) 当前方法与实际记录。它们是可检验的实践起点，随笔记和新研究继续改进；既有材料配额和文件格式不直接变成读者课程。

各篇列出的资料是取材方向。当前没有按每篇展开深挖，也没有选定贯穿全书的公司或数据。真实案例在本篇草图取材时按解释需要选择。

可用简化教学设定解释稳定关系，并明确其身份；现实制度、市场规则和经营事实按采用时点核实，保留原始出处。
