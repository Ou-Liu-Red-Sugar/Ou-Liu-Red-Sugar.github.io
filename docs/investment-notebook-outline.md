## 定位与范围

### 定位

这套笔记教读者在 Agent 时代学会投资。以股票和基本面研究为主线，先理解金融工具、业务与价格，建立自己的判断，再借助 Agent 扩大搜索、组织研究和持续更新，最后进入 Agent 辅助资产配置。

### 读者与学习目标

面向愿意认真理解投资的普通读者。金融基础在使用处展开，不要求先学测度论、随机分析、复杂估值计算或编程。已有相应知识的读者可通过主题导航直接进入需要的部分。

### 讲解深度

每篇解决一项可以说清的理解或投资判断问题。定义、例子和必要推导保持完整，复杂数字不作为学习门槛。

股票是核心对象。金融环境、基金、债券和现金进入真实比较；商品、房地产和合约工具按实际用途展开。

期权需讲清权利金流向、价格构成、市场报价与模型、退出及策略；期货和永续需讲清期间资金及完整持有结果；预测市场兼顾交易机制和研究用途。

制度、权利和会计细节只展开到足以解释当前选择。工具类型之间保留差别，不把所有市场都写成股票订单簿。

公司估值沿当前基本面、业务状态、适配定价参照和 Risk-Reward 方法组织；暂不编排 DCF/WACC 估值训练。资金时间、借款成本和债券现金流照其实际用途讲解。

图谱记录主题之间的知识、经济、决策和更新关系，其中存在合理回路。每篇的主要先修另列，任何一条图谱边都不自动成为先修要求。

### 全篇进程与阶段成果

开篇从投资者投入资金后希望获得什么进入，再认识股票、交易和基金。读者先有投资对象和持有过程，后面的经营与财报知识才有明确用途。

业务部分从客户付款推进到收入、成本、竞争、上下游及周期；财报解释这些活动怎样体现为利润、现金、资本和每股结果。价格部分据此比较未来情景、买入价格与现实替代。

工具专题在共同的资金、价格和风险语言上展开。期权、期货和永续最终回到组合目的与期间资金，预测市场接回事件对经营的影响；这些专题不构成进入 Agent 基本面研究的统一门槛。

Agent 部分复用读者已经理解的业务和判断，让搜索延伸到上下游一至两跳、竞争、技术和制度，再组织计算、协作与更新。最后以教学账户和已形成的研究完成一次配置、执行衔接和后续复评。

## 资料采用原则

金融市场基础的具名参考是 [现有 TeX 讲义](F:/Investing/workspace/learn/stochastic-processes-financial-markets/tex/main.tex)，采用其中与新题目相符的解释和实例；原章节顺序及进阶推导不规定新大纲。

Agent 研究和配置参考 [Investing-v3](F:/Investing-v3/README.md) 当前方法与实际记录。它们是可检验的实践起点，随笔记和新研究继续改进；既有材料配额和文件格式不直接变成读者课程。

各篇列出的资料是取材方向。当前没有按每篇展开深挖，也没有选定贯穿全书的公司或数据。真实案例在本篇草图取材时按解释需要选择。

可用简化教学设定解释稳定关系，并明确其身份；现实制度、市场规则和经营事实按采用时点核实，保留原始出处。
