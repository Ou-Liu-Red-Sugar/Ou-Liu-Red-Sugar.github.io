## 1. 敲定的结构

读者定位为具有足够数学背景的高年级本科生到研究生，默认微积分、线性代数、基本概率与证明阅读能力。正文采用紧凑定义、必要推导和实质分析任务；初等数学与可短释的金融常识作为就地参考。金融的真实合约、经济含义和制度条件仍须说透。

投资学笔记以 topic 为目录，以五个一级领域各自的推荐顺序提供连续阅读。每篇先交代对象和共同结构，再解释理由、拆材料、做练习；真实问题从这个基础上产生。公司拥有独立的资料与研究入口，知识词条按需要引用公司。

总纲含 **127 个有固定 ID 的内容节点**：市场与工具 29、企业财务 22、经济行业 18、投资组合 33、数学统计计算 25。其中 10 项是可查基础参考，其他为主线、专题或研究词条；Topic 导览、公司入口、研究快照和长证明子单元另计。这是长期内容地图，已有材料与待取材料在各项内区分。

## 3. 学习单元与固定模板

一篇的标准是读者用 10–20 分钟完成一个可检查的学习任务。多行业 topic 计“共同部分 + 一条行业带读 + 练习”，所有分支不累算成一篇的必读时长。术语短释义可内联，不能把每个名词都膨胀成文章。长证明按 QT11-P1、QT16-P1、QT17-P1 等稳定子 ID 独立阅读，不用折叠框掩盖超长先修。

| 类型 | 固定顺序；完整要求以写作规范为准 |
|---|---|
| T0 Topic 导览 | 对象与范围 → 板块结构 → 推荐顺序 → 可选分支 → 材料入口 |
| T1 概念与方法 | 位置 → 理由/定义/组成 → 完整实例 → 机制变式 → 对照迁移 → 检验 |
| T2 工具与契约 | 经济需要与安排 → 真实条款 → 生命周期及理由 → 收益/现金 → 比较 → 读契约练习 |
| T3 原始材料带读 | 共同全貌 → 选择分支 → 原始材料 → 业务定位 → 逐步读解 → 回到全貌 → 迁移 |
| T4 行业与经济机制 | 边界与结构 → 真实过程 → 机制传导 → 对照分支 → 证据与变化 → 分析任务 |
| T5 投资与组合方法 | 目标约束 → 共同框架 → 完整实例 → 替代/压力 → 资金影响 → 更新复盘 |
| T6 策略与对冲 | 原始敞口和用途 → 各腿与合约 → 资金过程 → 合计结果 → 失配/情景 → 替代 → 决策练习 |
| T7 定义与证明 | 对象约定 → 定义/命题/条件及理由 → 主线与完整证明 → 应用或反例 → 金融连接 → 综合迁移 |
| T8 数据与计算 | 检验对象 → 数据时间 → 方法/指标选择理由 → 完整运行 → 误差 → 解释与复算 |
| T9 现代研究 | topic 位置 → 版本和读取范围 → 对象方法 → 重建关键结果 → 与已有认识的关系 → 教学采用 |
| T10 基础参考 | 紧凑定义与条件 → 一个有区分力的例/非例 → 使用位置 → 可读文献；不强凑学习时长 |
| C0/C1 公司资料 | C0 企业/证券/业务/研究时间线；C1 研究时点/材料期间/分析依据/计算/变化 |

共同要求是 **解释为什么这样定义、这样安排或这样计算**。这贯穿期权权利金、逐日结算、会计期间、折旧、概率条件、损失函数和组合分散。契约的经济功能、规则原文、历史设计意图分别取证。单独列一个“为什么”标题后复述定义，不能通过教学复核。


现代与实战的取向贯穿五领域：真实结算与抵押、可成交价格与成本、数据时间、无形资源及资本约束进入正文。经典理论承担推导与比较职责。永续并入衍生合约，AMM 并入交易机制，稳定币与代币化并入权利及结算载体，不设置包揽一切的“新兴工具”类别。

估值使用本项目业务模型与 Risk-Reward 方法，见 [LD-BUSINESS](notebook-source-map.md#ld-business)、[LD-RR](notebook-source-map.md#ld-rr)。行业机制约束经营关系，财务材料校准利润与资本，估值接收同版业务状态和股东权利，组合管理再作资金取舍。默认不执行股票 DCF/WACC 及改名变体；债券现金流与衍生品复制保留各自学科职责。

知识图谱与目录和主线同源，记录先修、方法调用、推导、案例及证据等不同关系。设计见 [知识图谱](notebook-knowledge-graph.md)。Agent 版本带可读正文及指定 reference 单元，必须先实际读完再教学，见 [Agent 模板与资料包](notebook-agent-template.md)。

### P07 组合实施：风险、资金与可成交规模的联合预算〔T5，核心〕

- **产出**：把一个目标组合变成可实施的持仓计划，解释先触发的是哪一种约束及如何调整。
- **骨架**：①投资判断转成共同风险敞口；②市场风险、融资、抵押和现金余额各自预算；③场所、抵押币和转账时延造成的分割；④真实 bid/ask、深度和退出成本决定可交易规模；⑤压力路径下调整、退出和事后归因。
- **数学深度**：权重优化只作为有约束问题的一部分；用情景损失、资金需求及成交成本联合约束。边际风险贡献要写清风险度量；不将风险预算自动等同 inverse-vol 或 equal-risk，也不假设风险在压力状态可线性相加。
- **先修**：收益和风险敞口；选择一种已学工具即可。**案例**：同一教学组合可选股票＋股指期货、债券＋利率期货、数字资产现货＋永续；使用各对象真实规则，账户与行情数据写作时采集。
- **交互**：同一权重操作同时更新损失、现金、抵押和订单深度；可切换“统计风险较低但当日现金不足”和“账上有资产但此处不可用”的情景。
- **来源**：[MOD-CRYPTO-CARRY](notebook-source-map.md#mod-crypto-carry) §3.3、[MOD-BYBIT-LIQUIDATION](notebook-source-map.md#mod-bybit-liquidation)、[MOD-BYBIT-FUNDING](notebook-source-map.md#mod-bybit-funding)、[MOD-LVR](notebook-source-map.md#mod-lvr) §3.1；一般组合度量引用 P06，融资/成交定义引用 P08/P09，不把单一平台规则泛化成最优组合定理。**教学 Prompt**：请给我目标敞口和完整资金分布，让我做出可实施数量，再改变市场和抵押条件检查哪项约束先失效；每次要求我同时报告净收益与过程资金。

## 10. 资产负债表：按行业展开的完整样板设计

这个 topic 的学习产出是：读者能在所选企业的整张表中定位主要资源和义务，沿业务说明重点项目，查到附注，并解释一项余额变化。共同结构用完整表与紧凑说明呈现资产、负债、权益、内部板块和时点；熟悉者直接选行业，不先上三篇通识课；保留金融机构列报差异。之后选择行业，完整原表立即出现，每条分支完成计量选择、跨表联系与经营判断，不只识别几个科目。

共同开头：先用一张结构图说明资产、负债、权益与时点；再展示真实完整表。流动/非流动是常见组织方式，金融机构可出现不同列报；资产账面净额不是所有经营资源的完整价值。此后选择一个分支。

### BS-RETAIL：零售，代表候选 Costco

1. 先看货物怎样进仓、卖出、收款及向供应商付款。
2. 在全表定位存货、应付、现金及会员相关义务；接入各自附注。
3. 把门店物业和租赁放回经营基础设施，不把所有资源都理解成商品库存。
4. 解释两期主要变化，回查现金流；用周转与期间口径解释差异。
5. 迁移练习：另一零售商或另一期间的一小组原表行，要求说明先核对什么。

图形：货物与资金两条可点击流程；科目点击后显示原表、业务关系、附注和当前分析。代表材料 [BI-S05](notebook-source-map.md#bi-s05)。

### BS-MANUFACTURING：制造，代表候选 Caterpillar

1. 从材料采购、生产、库存到交付，区分原材料、在产品和产成品。
2. 连接设备、在建工程、使用和折旧，辨认资源形成与当前产出的时间差。
3. 区分工业销售对应的贸易应收与金融业务融资应收，避免将整个集团简单当纯制造。
4. 结合会计政策、业务范围和两期变化解释，而非机械比较行业比率。
5. 迁移练习：判断一组库存变化需要哪些产量、订单和减值资料。

图形：生产阶段与资本投用的双时间轴；工业业务与金融业务切换。代表材料 [BI-S06](notebook-source-map.md#bi-s06)，正式制表前补原表核对。

### BS-BANKING：银行，代表候选 JPMorgan

1. 先从存款等资金来源和贷款/证券等资金运用理解业务；不套采购—库存—销售链。
2. 读资产分类、信用准备、期限和流动性，再看相应负债与资本。
3. 把表内金额、净额列示、风险暴露和普通股归属区分清楚。
4. 用附注和资金结构补充“账面总额很大/现金很多”的表面印象；比较时使用银行合适的口径。
5. 迁移练习：对一段真实历史压力材料，区分信用损失、利率重估与提现需求。

图形：资产和负债的期限/资金来源视图；选择一种压力显示传导。[BI-S07](notebook-source-map.md#bi-s07) 为带读，[BI-S17](notebook-source-map.md#bi-s17) 为独立历史案例；不会把历史失败归因简化为唯一因素。

### BS-SOFTWARE：软件订阅，代表候选 Salesforce

1. 从合同、开票、履约和收款进入；将应收、未实现收入和RPO分别定位。
2. 解释合同余额与现金的关系，再看取得合同的成本及相关资产。
3. 将商誉、收购无形资产与自己研发形成的经营资源区分，解释账面边界。
4. 回到现金、债务、权益和股数，完成整张表的阅读；不因“软件”标签忽略资本与义务。
5. 迁移练习：给新的一期合同余额披露，要求解释哪一项不能直接推成收入增长。

图形：合同—开票—履约—收入—收款多轨时间线；RPO等披露保留自身定义。代表材料 [BI-S08](notebook-source-map.md#bi-s08)。

行业选择不穷举世界行业。保险、房地产、资源、公用事业、医药等分支在有教学需要时按资料预检加入。AMZN 和 GOOG 只是已有材料候选，并非栏目边界或每个行业的默认代表。

事件交互必须表达会计与业务的传导。小型教学例中，赊购存货 100 对应存货增加 100、应付增加 100，当时权益不变；赊销收入 150、结转成本 100，连接应收、存货与当期利润，显示在忽略税费等条件下净资产增加 50，而现金尚未收到。每条边注明事项、金额和方向，并能回到真实材料。读者点击“付款”“收款”时沿同一过程继续更新，不能无条件把所有事件连到权益。

## 11. 期权：把“为什么有权利金”落到教学顺序

M15 与 M18 分别完成契约和价格的职责，避免一篇既没讲明白选择权，又急着引入 Black–Scholes。

1. 先说明标的交易所需要安排的未来事项。比较“届时必须按约定交易”与“届时可以选择是否按约定交易”，逐个状态看双方的义务。
2. 引入普通看涨/看跌权利：买方可放弃不利的行权；卖方按条款承担相应义务。读者应先能解释这份选择权多给了什么，再看到公式。
3. 把行权价与权利金分别放在时间线上：前者参与决定未来交换或结算，后者是取得这份权利的交易价格。交易市场通过买卖报价形成价格，交易所的规格并不统一规定一个“风险收费率”。
4. 改变标的价格、执行价、剩余期限和未来分布，观察同一选择权可能值多少。说明预期、风险定价、融资/分配与市场条件的作用；并非只用“卖方有风险所以收费”结束解释，也不据此推出卖方必有正期望收益。
5. 在真实合约和报价上分开到期支付、含权利金的损益与投入资金回报。具体产品决定支付和担保方式；CME 的 equity-style / futures-style 材料用于避免把所有期权说成一种付款制度。
6. 迁移题让读者解释：同一标的的两个不同期限合约为什么不能只按当前内在价值比较；把选择权换成双方都有义务的远期后，权利义务及交易价格的结构发生了什么变化。

这一节的交互顺序是“权利义务对照 → 生命周期现金流 → 价格因素 → 损益分解”，每一步有静态等价说明。研究论文与定价证明作为内联分支，不成为第一次读懂契约的门槛。材料入口：[LD-OIC](notebook-source-map.md#ld-oic)、[LD-CME-STYLE](notebook-source-map.md#ld-cme-style)、[MP-OCC](notebook-source-map.md#mp-occ)、[MP-MIT-OPT](notebook-source-map.md#mp-mit-opt)。

## 13. 公司库与可复用资料

公司库入口独立于五领域。C0 记录企业身份、业务集合、对应证券和研究时间线；C1 记录某次研究的截止日、所用财报期间、来源、分析、计算和更新。需要价格时另记报价时间。Alphabet 与 GOOG/GOOGL 的关系要清楚；公司实体不等于交易代码。

同一份报表、附注或经营资料拥有材料 ID，被 BF-05、BF-12 或其他 topic 引用时保留同一原值与时期。教学解释归各 topic。日期至少区分“报告覆盖期”“材料公布日”“研究截止日”“文章修订日”；旧研究不会被新日期静默替换。

首批 AMZN、Alphabet 研究保留在公司库，另按教学需要选择零售、制造、银行和软件材料。研究库的本地内容在公开写作前选取并核来源；不自动把整个私人研究库或内部路径导出到网页。完整公司库不限于这几个行业。

## 14. 生成前的资料与写作流程

采用 [写作规范第 2 节](notebook-authoring.md#2-先检索再交给-chat-或-agent-写作) 的唯一流程：先核 topic 与已有内容，再查教材/讲义、原始案例和近期研究，形成来源与骨架对应后才交接成稿。默认检索近五年，并追溯必要经典材料；稳定定义无需硬配新论文。每项记录目录、摘要、相关节或全文的实际读取层级。

Chat 协作使用当前模板和有限的词条组；上下文过长就新开。按用户要求通过 codex-with-chatgpt 实际读取具名本地内容并记读取范围，不能仅凭连接状态声称读过。逐篇向写作者追问“读者只读完这个词条，真的能学明白吗？”，用独立解释和迁移题检查，并由 Lead 复核来源、计算与图文。

教学 Prompt 与 Agent 版本同源，并附可实际读取的必读原文、指定完整单元、版本和读取目的。Agent 必须实际读完当前必读范围后再教学，发布时链接可访问与运行时已读取分开记录；详见 [可复制模板与示例资料包](notebook-agent-template.md)。例：M15 Prompt 应要求 Agent 先让读者解释未来必须交易与可以选择交易的差别，再辨认真实合约中的行权价/权利金/乘数，逐步核现金与损益，最后换合约检验；不是一句“请讲讲期权”。BF-05 则按读者所选行业从完整原表定位项目，不把其他行业的指标硬套过来。

## 16. 业务估值、现代合约与知识图谱的交接

公司投资的核心顺序为 P04 → P28 → P29 → P30 → P05/P31。完整案例沿现行项目方法做三类必要校准，短词条使用其中一项可复核关系；资料缺口不靠任意概率、行业固定倍数或当前价格倒推补齐。业务研究与独立估值分组可以不同，资金低谷、融资和股数属于经营路径的一部分。
