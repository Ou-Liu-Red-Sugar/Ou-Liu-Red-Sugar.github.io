网页与 Agent 版使用同一份已核正文、计算、分支、练习和来源。Agent 版补充教学任务、必读范围与运行协议，不独立改写事实。面向有足够数学背景的高年级本科至研究生；读者可以选择直接讲解、完整推导或互动练习，已会内容不反复问答。

## 2. 必读材料与执行协议


### 核心区分

**发布时能访问，不等于本次 Agent 已读取。** 书目清单、搜索摘要、网页标题、成功打开链接、文件存在，都不等于所需正文已到达 Agent。每次新教学会话应从实际工具读取开始；同一会话中已经完整读取的相同版本/单元可以复用，不机械重复读取。

资源层级与本次读取状态分别记录：

| 资源能提供什么 | 可用于什么 | 不可据此声称什么 |
|---|---|---|
| 原文全文：开放 HTML/PDF/TeX、合法随包文件、可访问本地文件 | 读取指定完整章节、证明、图表与必要上下文 | 有全文 URL 就已读全文 |
| 合法摘录或选定章节 | 支持摘录覆盖的具体内容 | 已读其他章节或全文 |
| 目录/书目页 | 版本、主题覆盖、进一步定位 | 公式、推导或制度细节已验证 |
| 摘要 | 作者概述的研究目标和主要主张 | 方法、识别、证明、成本和实证细节已核验 |
| 搜索节选 | 发现候选材料 | 正文读取已经完成 |

必读要求可以是“读完 §5.10”而非“读完整本书”。但它必须是足以支持当前教学的完整阅读单元；不能靠几个关键词命中代替。证明任务包含命题、条件、符号约定、证明及其具名依赖；实证结论包含任务、样本/时间、方法、评价与相关结果。

### 运行时协议

1. **确认当前学习范围。** 使用所选分支及本篇正文；先修仅诊断本篇确实需要的内容。识别必读材料，选读材料只有被采用时才转成对应问题的必读。
2. **实际获取。** 用浏览/文件读取工具打开指定 URL 或随包文件。核对返回的标题/版本/范围，发现只有摘要、登录页、目录或文件清单时如实记录，继续找明确可读的正文入口。
3. **完整读取所需单元。** 分页或分块读取到所需单元结束，包含前文约定、必要表图和脚注。PDF 符号或图表解析不可靠时查看原页；TeX 读取相关宏定义与 include 文件。不能只看搜索命中的几行。
4. **形成简短内容对应。** 每项记录实际位置、读到的关键设定和它支持哪一步教学。例如“§5.10 的训练集仅含当前预测点之前的观测；该限制需要落实到预处理拟合，不仅是分割最终数据表”。后半句若为本站推论须标为推论。
5. **满足后才开始该范围的实质教学。** 所有当前必读单元读完之后，基于材料给一项高密度诊断任务或按读者要求直接讲解。引用跟着对应命题或计算，不在末尾堆书名。
6. **读取失败时自动处理缺口。** 先尝试指定的可读等价版本或作者/机构正式全文，不新造批准步骤。等价性包括版本、条款期间、定义和假设；新的替代来源实际读完后记录采用范围。仍缺失则说明具体缺少哪一个必读单元及原因，不凭训练记忆补成已读讲解，不宣称已完成本篇。

“读取校验”依赖实际取得的内容及其位置、与教学相关的设定复述；不靠让模型报一句“我已阅读”，不引入无意义哈希或重复下载。它不能从技术上保证理解，但能让来源与使用之间可检查。

- 来源：BI-S05，Costco Wholesale Corporation，Form 10-K，财年截至 2025-08-31。

## 6. 业务模型与 Risk-Reward 的本地及公开资料包

估值词条的内部写作包引用当前 [业务模型方法](notebook-source-map.md#ld-business)、[Risk-Reward 方法](notebook-source-map.md#ld-rr) 和 [研究模板](notebook-source-map.md#ld-research)，并附一个实际研究快照的业务、校准、状态、条件价格和股东所得材料。涉及哪个步骤，就明确必读的完整方法单元与案例依据，不把全库交给 Agent 自行猜测。

公开教学包必须包含本站实际讲清的方法正文、可公开原件和必要计算。只给 F 盘地址或一个私有技能名称不构成可读 reference；未取得公开材料时保留该缺口。本地包可引用真实可访问路径，并由执行 Agent 实际读取。研究时点、材料期间和价格时间分别保留，旧案例不自动切到最新研究。

知识图谱导出当前词条的文字关系：主 topic、必要先修、调用方法、案例、支持来源及各自范围。必读清单由本次教学范围选择；图中每个邻居并不自动成为必读。两者共同沿 [知识图谱规范](notebook-knowledge-graph.md) 维护。

## 7. 写作者的交付检查

交回一个词条时，须用实际执行结果回答：指定原文是否读到且范围足够；正文里的解释与计算能否定位；Prompt 是否有概念专属任务；仅有文字与静态数据时能否完成教学；读者是否能够独立解释并迁移。读取日志只记录真实行动，不预填“全文已读”，也不把未来计划写成完成。
