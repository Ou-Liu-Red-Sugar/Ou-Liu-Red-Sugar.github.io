# 投资学笔记：写作、词条模板与资料流程

版本：2026-09-21。本文是投资学笔记唯一现行写作规范。知识范围与逐词条骨架见 [详细大纲](investment-notebook-outline.md)，本轮实际检索及采用依据见 [资料地图](notebook-source-map.md)。

本轮确定的是内容规范，网页与生成器尚未实现其中全部字段和模板。已有页面不能因本文件更新而被标记为完成。站点其他数学笔记不自动迁入投资学目录。

## 1. 组织原则与学习单位

知识目录有五个一级领域，每个领域有独立的推荐主线。领域内部按 topic 组织；主线选取核心内容，选读分支在对应位置展开。跨领域内容使用明确的概念引用或局部先修，不把所有领域串成一条必修课程。

公司实体有独立公司库，按行业和业务类型检索。公司库保存公司介绍及有时点的研究记录；知识词条引用其中的材料，组织适合当前 topic 的教学。行业机制、行业研究与公司实体分清归属。AMZN、GOOG 是首批已有材料，不限制后续行业和案例范围。

目标读者是具有足够数学背景的高年级本科生到研究生。默认熟悉微积分、线性代数、基本概率、抽象定义和证明语言；不把全部测度论、随机分析或金融专业训练作为默认前置。基础金融术语、复利、百分比和常见符号可以简述或就地查询，正文集中解释概念的经济内容、必要假设、完整推导、真实材料和分析取舍。数学背景不能代替对结算、抵押、会计和数据制度的准确交代。

一篇学习词条以完成一个明确任务为单位，设计为约 10–20 分钟有内容密度的阅读、操作与思考。多分支 topic 的时长计算共同部分与选定的一条分支，不把所有行业都算作必读。已具备的数学基础和可短释的金融术语转为可查参考；超出一个学习单位的推导或策略拆成有先修关系的词条。Topic 导览、基础参考、公司目录和来源记录不强凑学习时长。不能靠反复直观比喻、微小步骤和重复练习把短定义拖成一篇。

开篇交代 topic 的位置、对象和共同结构，再展开真实材料。每篇还要解释相应概念或安排的理由：它处理什么关系，为什么使用这些定义、规则或步骤，换一种安排会改变什么。契约与制度解释参与者的权利、动机和取舍；会计解释记录对象与期间；数学解释定义所捕捉的性质及假设的作用。经济解释、正式制度目的、历史起源各自有依据，不能从结果倒编设计者的意图。问题从这些关系与材料中产生，不用悬空提问代替结构介绍。允许自然口语，段落持续推进；数字、图和练习完成解释职责，不用字数或反复小结制造“充实”。

同类型词条使用下面同一份固定模板。固定的是教学职责与主要顺序；行业分支中的分析对象、细节顺序和图示依据该行业的真实业务调整，不做只替换公司名称与数字的复制。

现代与实战是内容选择的默认立场：先面对今天的资产、合约、机构、数据和交易方式，再选择能解释它们的理论。合约同时研究资金、抵押、清算与实施；组合同时研究估计不确定性、流动性、成本和约束；企业同时研究业务集合、无形资源、资本形成与普通股所得。经典模型保留其清楚的假设、推导和比较职责，不自动转为实务预测或默认操作。历史讲义支持稳定原理，现行市场事实与制度使用当期原始资料；新颖性也不能替代机制和证据。

## 2. 先检索，再交给 Chat 或 Agent 写作

以下流程适用于新词条、实质重写、增加行业分支和研究专题，也适用于交给 Chat 写作。文字微调、排版修复不重新检索无关文献。

1. **确定范围。** 写下 topic、学习产出、模板、主归属、必要先修、拟解释的材料和暂不覆盖的内容。先检查已有词条、公司库、已有来源与具名本地讲义。
2. **检索成熟教学材料。** 查教材的正式版本与章目、大学公开讲义、专业机构教学资料；实际阅读本次内容对应的章节或片段。目录可支持结构规划，不能充当公式、制度细节或实证结论的证据。
3. **检索原始实例。** 财报及附注、合约规格与结算规则、监管文件、官方统计和可追溯历史数据优先。记录材料对应时期与取得时间。需要历史行情的实例先核实数据能否取得，再设计依赖这些数据的实验。
4. **检索现代研究。** 默认检查写作日前约五年的相关研究，并按引用关系回查必要的奠基文献。记录实际检索范围、采用理由及不采用理由。没有会改变经典定义的近期研究时明确记录检索结果，不给每个定义强配一篇新论文。发表年、工作论文版本日和检索日分开。
5. **形成材料与骨架的对应。** 明确哪些资料负责定义、机制、规则、真实案例和新研究；核对术语、数据口径与争议。先得到足够支持当前教学范围的材料，再进入成稿。未读全文的条目标明目录、摘要或相关节的实际读取范围。
6. **交接写作。** Chat 或 Agent 接收当前模板、范围、来源索引、经核材料和已有词条，而不是接收一项没有材料的“自由写作”任务。发现材料缺口，先补取材料并登记，再继续相应段落。
7. **核对与教学复核。** Lead 核事实、规则、算术、推理和图文一致性。向负责写作的执行者逐篇明确追问：“读者只读完这个词条，真的能学明白吗？”要求指出读者可独立完成的任务、稿件中的具体缺口、检验题和解析；修正后记录实际采用结果。
8. **同源生成与验收。** 正文、案例、引用预览、教学 Prompt 和 Agent 版本共同取自已核内容。新增交互同时有静态解释；检查所涉内容和功能后交付，不因完成本地编辑自动发布。

来源记录至少包括：稳定来源 ID、标题、作者或机构、版本与发表日、原链接或具名文件位置、材料期间、取得日、实际阅读范围、用于哪些词条与结论、支持范围、重要分歧。正式正文只引用实际支持该处说明的来源。

现代研究区分作者主张、研究样本与方法、复现或外部证据、编辑采用。工作论文不写成已被公认的定理；特定市场与时期的策略表现不写成普遍有效。教材的经典模型可以讲清假设与用途；本项目公司研究的实战默认沿业务状态与 Risk-Reward，不把股票 DCF/WACC 重新引入默认研究流程。债券的契约现金流计算、资金时间与复制定价仍按各自 topic 讲述。

## 3. Chat 协作与上下文

五个领域保留各自的作者职责，具体会话按具名批次新建。一次 Chat 负责一个相关词条批次的阅读、规划与成稿，或一项边界明确的审校；不以领域连续性为由长期复用同一会话。当前分组、首批材料与编辑确认沿 [生产计划](notebook-production-plan.md)，实际会话、文献读取、批次与采用状态记在 [生产记录](notebook-production-state.json)。术语、材料版本与跨领域接口由正式文件和 Codex 保持连续。

作者先实际阅读相应教材、讲义、论文和原始材料，可自行检索补充，再交阅读报告和写作方案。Codex 核支持范围、教学顺序、案例、推导与跨领域接口，并确认具名批次后，作者才进入成组正文。已有目录和资料清单仅用于定位，不抵扣原文阅读；上一位执行者读过不等于当前 Chat 已读。

成组正文按用户指定使用界面实际可选的 6 Pro，文献补读、后续规划和审校使用 xhigh；发送时核对 Chat 模式、模型及档位，不靠模型自报。本轮 Pro 调用沿生产计划控制在 20–30 次范围，目标 25、上限 30；内容组不等于调用数，多个已经阅读并获确认的相关组可合并成稿。每组相关节点先形成连续解释，再按固定模板和 ID 拆分，保留各篇可独立完成的学习任务。优先以完整文件交付长内容，需要续写同样计次，不能为一次输出削薄内容。一般返修交 xhigh 与 Codex，Pro 实质重写合并问题后使用。

进入下一成稿批次、从作者改为独立审校者或处理另一个领域时，先保存交接包，再开新 Chat，不等到引用混乱才切换。一轮审校的问题合并后可在该会话返修；仍需持续追加新任务时新建下一会话。交接包给出完整当前稿、已确认决定、来源版本与读取单元、冻结输入、未决问题和下一步，不复制整段聊天历史。新会话先核工作区身份，实际读取这些文件及当前采用范围所需原文；上一个 Chat 的“已读”不能代替本次读取。

本地材料优先通过 codex-with-chatgpt 读取：先核工作区身份与实际可访问范围，再让 Chat 实际读取具名文件，记录所得范围；连接启动不能充当读取回执。结果默认从页面文件或代码块回收，由 Codex 保存和核验。普通读取失败沿已授权的诊断、重连及必要材料包上传顺序处理，读取、页面回收与本地写入分别记实。

交接至少包含范围、模板版本、主归属和先修、实际已读来源、研究截止与材料期间、真实案例/教学变式身份、输出责任及学习检验。Chat 负责文献阅读、规划和写作，Codex 负责采用、事实与计算核验、统一源维护和页面实现。逐组编辑确认无需用户重复授权；改变既定方法或大框架时说明具体影响。

## 4. 所有学习词条共用的内容字段

| 字段组 | 必需内容与用途 |
|---|---|
| 身份与归属 | 永久 ID、标题、语言、主领域与 topic、模板类型；分类或标题变化不改变已公开 ID |
| 学习定位 | 对象、位置、一个主要学习产出；核心/选读/基础参考、默认读者水平、预期时长、上一节与下一节 |
| 先修 | 必须已会的内容与可就地补充的内容分别列；不以一整本数学课替代局部先修 |
| 内容关系 | 所属 topic、必要先修、方法调用、推导依据、实例和来源分开记录；沿 [知识图谱规范](notebook-knowledge-graph.md) 生成图和关系列表 |
| 正文 | 依模板编写的共同解释、材料分析、推演、互动与学习反馈 |
| 分支 | 可选行业/业务/合约/情景及其选择理由，默认或推荐分支、返回共同部分的连接 |
| 材料与来源 | 来源 ID、定位、材料时间、实际口径；事实、推断、假设及教学变式能区分 |
| 图与交互 | 要解释的关系、输入单位、默认值、计算或推导、边界、静态等价说明 |
| 检验理解 | 至少覆盖解释和迁移两种学习反馈；题目有完整解析，不能只报答案 |
| Agent 教学 | 概念专属 Prompt、可实际读取的必读文献及定位、先读后教协议、先修诊断、推演任务、反馈准则和同源上下文 |
| 维护 | 修订日期、真实对应的译文 ID、需要更新的规则/数据触发点、实际复核记录 |

这是一份内容合同，不规定当前 JSON 已有全部实现。后续实现应统一迁移字段及生成器，不能在 Markdown、网页和 Agent 文件里维护三篇不同文章。

## 5. 固定正文模板

### T0 · Topic 导览

用于每个一级领域、二级 topic 的入口；不充当一篇概念正文。

1. 本 topic 的研究对象、在领域中的位置和范围。
2. 结构图或完整板块概览，说明组成与关系。
3. 推荐核心顺序，每一节写一句学完可做的事。
4. 选读分支及适用读者，明确从哪里进入、回到哪里。
5. 真实实例入口与其他领域的少量必要连接。

### T1 · 概念与分析方法

1. **位置与对象：** 说明概念描述什么，先给足以看懂后文的整体结构；默认已掌握的知识用紧凑引用，不重复入门。
2. **由来、定义与组成：** 说明为何需要这个概念、它捕捉什么关系，再列要素、单位、口径和适用条件；引用既有定义而不重复另造。
3. **贯穿实例：** 展示一个真实材料片段，依次识别、计算或解释。
4. **机制与变式：** 改变一项有意义条件，用图或计算看哪些结论随之变化。
5. **对照与迁移：** 换一个对象或边界情况，指出同与不同来自哪里。
6. **检验理解：** 解释题和迁移题，附推理；衔接本领域下一节。

适用：风险暴露、营运资本、相关性、行业集中度等。复杂行业实例使用 T3 分支，严密定理使用 T7，不强塞进本模板。

### T2 · 金融工具与契约机制

1. **工具的位置与经济作用：** 从参与者的需要解释权利义务怎样安排、各自换取什么，以及与其他安排的差别。期权必须解释选择权为何不对称、权利金作为期权价格的经济含义、市场报价如何形成；不能只写“买方付钱，卖方承担义务”。合约规则、交易价格与价格模型分清。
2. **读一份真实契约：** 标的、单位/乘数、数量、币种、期限、交割或结算方式及其他关键条款。
3. **生命周期与机制理由：** 从建立头寸到期间现金变动，再到平仓、到期、行权或交割；说明为何这样结算或担保，怎样改变信用与资金关系。权利金与保证金、选择权价值与支付时点分别解释。
4. **收益与现金：** 区分合约收益、交易盈亏、现金流、占用资金；列明费用和取值时点。
5. **比较分支：** 根据该工具选择标的、结算或条款差异，展示经济影响。
6. **实际阅读练习：** 换一份合约，让读者识别条款与结果；相关策略链接到领域四。

图表职责：合约卡、权利义务连线、事件时间轴、现金流水与价格/盈亏图。一般定价原则通过概念引用补充，具体策略不在此复制。

### T3 · 原始材料带读（含财务报表）

1. **共同结构：** 先介绍整份材料的板块、口径和用途，以及采用这种记录方式的理由。资产负债表须先呈现资产、负债、权益及其内部划分，说明时点余额与期间流量的区别，不能从零散科目开讲。
2. **选择分支：** 说明各行业/业务类型在本 topic 中为何有不同关注点；读者选择一条即可完成本次学习。
3. **真实材料：** 展示代表对象的原表/必要重排版，保留完整主板块、期间、单位和原始定位，明确重排与摘选范围。
4. **业务定位：** 从该对象的经营活动解释材料中的关键项目，再确定本分支的阅读次序。
5. **完整分析：** 围绕本分支最重要的两至三个关系，指到原表行、查附注、做必要分解并连接其他材料；图与解释紧邻对应数据。每段推进一个完整分析任务，交代依据、计算与可得认识；不把逐格读数当作教学主体。
6. **回到全貌：** 把重点发现放回整份材料；区分已解释与需进一步材料才能解释的部分。
7. **迁移练习：** 使用另一时期或另一对象完成部分带读，提供解析；可切换其他分支比较。

行业分支共用“材料—业务—分析—回到全貌—练习”的职责，具体分析中心不同。银行不照搬工业企业周转指标；公司分部边界不按股票标签推定。小型合成例可以解释分录或机制，标明教学身份，并服务于真实材料。

### T4 · 行业与经济机制

1. **对象边界与结构：** 产品、参与者、地域、时间及统计口径；行业与业务边界先说清。
2. **真实过程：** 展示价值链、供需或资金关系，用代表参与者和原始数据定位各环节。
3. **机制展开：** 需求、供给、成本、竞争、资本或制度如何传导，明确时间差和替代路径；保留有解释作用的经济模型、约束和比较静态，基础术语就地查阅。
4. **行业/时期分支：** 选有实质差别的例子，比较为何传导结果不同。
5. **证据与变化：** 对照可观测指标、不同解释和新研究；共同变化不能直接推出因果。
6. **分析产出与练习：** 读者画出关系、解释一项变化或判断哪些资料仍需补充。

图表职责：行业结构图、量价与成本分解、传导图、可切换历史窗口。具体公司事实引用公司库。

### T5 · 投资判断与组合方法

1. **方法位置与目标：** 要处理的资产、持有期、目标、约束及所需输入。
2. **共同框架：** 明确从经营或市场材料走到判断的步骤，指标身份与单位。
3. **完整实例：** 按一个有资料时点的案例逐步建立判断与必要计算。
4. **替代与压力：** 比较合理替代及改变关键条件后的结果，说明取舍依据。
5. **组合与资金影响：** 与现有风险来源、资金时间和现金安排的关系；教学组合使用具名历史或明确模拟数据。
6. **更新与复盘：** 哪些观察会改变判断，怎样记录前后变化；附独立练习及解析。

不读取用户账户来填教学例子。比较真实历史策略与持仓时记录完整信息可得时点，不把后来数据写回当时决策。

### T6 · 策略与对冲实战

1. **用途与原始敞口：** 策略服务什么目标，开始时持有什么、担心什么变化、允许牺牲什么；推演为何需要这些腿及其方向，不能先报策略名称再套收益图。
2. **结构与真实合约：** 逐腿列多空、数量、乘数、期限、行权价、币种、报价时点与成交假设；明确与原头寸的关系。
3. **资金与生命周期：** 建仓资金、担保/保证金、期间现金变动、到期/指派/展期及退出。
4. **结果分解：** 原头寸、各腿和合计结果并列；到期图与期间变化分开；收益率写清分母。
5. **情景与失配：** 检查价格、时间、波动、相关性或基差的相关变化，展示组合剩余风险及资金路径。
6. **现实替代：** 与不操作、减持/持有现金或另一种策略比较同一目标与约束；不以权利金或较小保证金自动判定更优。
7. **决策与复盘练习：** 让读者选择结构、计算数量、安排资金、解释退出条件，再展开答案。

期权必需处理：到期盈亏与期间价格、行权/指派与结算方式、买卖价差/费用、各腿期限和数量、有限亏损结论的具体条件。历史报价未取得时标为待采集，不能用生成数字声称历史成交。

期货必需处理：原始现货敞口、方向、对冲比率和取整、合约乘数、现金保证金路径、基差与展期/交割。名义金额、合约市值、保证金和最大可能损失分别呈现。

图表至少覆盖本策略真正需要的两种视角，例如“到期收益图 + 期间资金流水”，而不是每篇机械添加相同图。可切换真实实例和清楚标注的压力变式；所有默认结果都可静态阅读。

### T7 · 数学定义、命题与证明

1. **对象、用途与约定：** 说明数学内容的位置和符号，直接采用读者已有的数学语言。
2. **定义、命题与条件：** 完整给出空间、可测性、可积性及其他实际需要的假设；说明定义保留什么性质，结果为什么值得建立。
3. **证明：** 先给证明主线，再完成承重步骤，说明条件用在哪里。区分直觉、正式结论与引用结果，例行代数可合并；超过一个学习单位的证明单列并准确引用。
4. **应用或反例：** 走通一个有实质内容的应用，或用反例解释去掉条件后的变化；不强制每篇先铺陈初等例子。
5. **金融或数据连接：** 指明对象对应关系、测度与模型身份，不用定价概率代替现实概率。
6. **综合迁移：** 用一项足以检验独立重建能力的推导或迁移任务收束，提供完整解析。

定理编号只引用实际核验的位置。公式使用 LaTeX，自然断行；长推导按逻辑分步，不以缩小字号或整页横向滚动替代排版。

### T8 · 数据、计算与验证实验

1. **实验对象与待检验内容：** 区分描述、估计、预测、因果与策略评价。
2. **数据与时间：** 来源、样本、单位、复权/缺失处理、当时可得版本和训练/验证/测试边界。
3. **方法与基线：** 先说明要估计或改善什么、评价量为何对应这个目标，以及换一种合理评价量可能怎样改变结论，再给可重算流程、参数及比较对象。预测条件均值与控制尾部损失不默认使用同一种损失函数；模拟写清生成假设与随机种子。
4. **完整运行与关键对照：** 从输入到输出，解释有意义的中间值、默认结果和一次关键对照。可直接使用矩阵与伪代码，选一个关键环节供手算核对；改变参数时同时更新相关计算，未实际运行不声称得到结果。
5. **误差与稳健性：** 样本外、滚动窗口、费用、缺失与口径敏感性，按实验目的选择；金融时间序列不能机械套随机拆分。
6. **解释与复现实验：** 说明可支持什么、哪些仍未检验，并让读者重算或改变一项条件。

交互的模型输出与真实历史观测分开标识。网页简化版本和完整复算材料使用一致输入与口径。

### T9 · 现代研究阅读

1. **嵌入位置：** 论文与已经学习的 topic 有何关系，为何值得读。
2. **书目信息与实际读取范围：** 版本、日期、作者、链接，明确工作论文或已发表状态。
3. **研究对象与方法：** 样本、识别/模型、主要假设与评价目标。
4. **核心结果的重建：** 阅读相关定义、公式、图表或实验，尽可能复算一个局部结果；区分作者主张与编辑解释。
5. **与已有认识的关系：** 支持、修正或提出争议之处，以及适用边界与未验证部分。
6. **教学采用：** 明确哪些内容进入主线，哪些保留为选读；附复述或复核练习。

研究阅读默认作为相关 topic 的分支。每次聚焦一项主要命题、识别安排或实验比较，读完支撑它的设置、方法和证据；必要证明依赖不能藏在未读部分。新颖性本身不使其成为入门必修。

### T10 · 可查基础参考

用于读者可能需要确认、但无需再上一整课的定义、约定和基础结果；保持可深链的稳定身份。

1. **紧凑定义与条件：** 给出对象、符号、单位或适用假设；涉及命题时准确标注采用版本。
2. **有区分力的例或非例：** 一例解释最容易混淆的界线；不堆砌重复练习。
3. **使用位置：** 指向需要该定义的词条或证明，并说明在哪里使用；必要的长证明另有学习单元。
4. **可读来源与 Prompt：** 给实际可取得的相关原文单元，按同一先读后教协议解答；默认回答当前疑点，不强制延长为完整课。

基础参考不强凑 10–20 分钟。更改为参考页不取消原有 ID、引用和必要条件。

### C0/C1 · 公司入口与有日期的研究记录

**C0 公司入口**固定包含：企业与证券身份、业务集合、行业/业务标签、研究记录时间线、已核材料入口、相关教学 topic。公司与具体股票类别、上市地、币种分别记录；多业务公司可有多个业务标签。

**C1 研究记录**固定包含：研究截止日与材料期间、研究范围、业务和分部边界、关键原始材料、分析与必要计算、判断及依据、与上一版本的变化、关联教学实例。若涉及价格另记报价时点，若只使用业务资料不填无关估值。

旧研究记录保留原身份与日期；新一期新建记录，不静默覆盖旧案例。公司入口可指向当前记录，历史教学案例仍指向它实际使用的版本。

## 6. HTML、引用与 Agent 版本

共用符号与量级的唯一来源为 `notebook/notation.json`，由同一生成器提供网页内联符号表、独立参考页与 Agent 版。数学期望统一用 `\mathbb{E}`，条件期望写作 `\mathbb{E}[X\mid\mathcal{G}]`，需要时标明测度 P、Q。帽号作用于整个期望算子。方差、协方差等运算符使用正体；变量在首次使用时定义，权益、利润、能量、状态空间等局部 E 保留其实际含义。引用原件中的符号保留，并说明对应关系。

金额和数量统一使用 K、M、B，分别为 $10^3$、$10^6$、$10^9$；表格在表头或紧邻说明处标币种、量级与期间，例如“单位：USD M”。每股、每合约、功率、能量等单位单独说明。改变量级必须同步换算数值，原始输入和计算精度保留；展示小数最多三位并省略末尾多余的零。原始来源标题、引文、原件和代码标识不作机械替换。

行文直接讲对象、机制、证据和推导，可适当口语化。句末使用英文句点 `.`，包括定义、命题、证明和解析等标签。基础定义与推导直接呈现内容，出处放在紧邻脚注；不在正文汇报“某讲义采用同一定义”或“本次复审查看了该页”。数学条件、真实合约条款、数据期间及会改变结论的假设放在实际用到的位置；同一条件已有清楚定义，后文直接沿用。编辑读取过程、审校经过和未开展的工作留在 provenance 或维护记录中；正文与脚注保留读者需要的来源、定位和解释。删除重复的自我辩护、无关限制与“这不是……而是……”式铺垫，保留用于区分概念、构造反例和解释风险的实质比较。语言修改同样核对公式、数值、引用和段落衔接。

图表按解释职责选择：构成图帮助看全貌，传导图解释方向与连接，时间轴解释先后，曲线与情景切换解释参数变化。箭头写清经济含义；不靠高亮框代替解释。

表格注明单位和期间，数字使用齐线字形；比较数据需要时使用等宽数字。图表颜色之外还要有标签，支持键盘、窄屏、静态查看和打印。行业切换、全部展开和深链共同保留，切换不丢失共同概念。

概念引用就地预览定义、必要条件及当前段落所需说明；来源引用显示标题、期间/版本、具体定位和支持本句的摘要，并提供原文链接。摘要明确为编辑概述。完整阅读入口保留，但不要求读者频繁跳页。

知识图谱复用这些引用、内容身份和预览；默认展示当前词条的一跳关系，可展开方法、证明或实例与证据。推荐路线相邻不自动构成必要先修，普通引用也不自动成为推导或因果。公司、证券、有日期的研究保持独立身份，旧案例引用固定版本。具体节点与关系、方向、时间和检查要求以 [知识图谱规范](notebook-knowledge-graph.md) 为唯一主要定义。

每个概念配置专属教学 Prompt，并随 Prompt 交付可实际读取的 reference 包。必读项给作者、标题、版本、开放全文链接或随包文件、指定章节/页码、读取目的与支持范围；目录、摘要、搜索节选不能冒充该处需要的正文。完整论文结论需要读取相应方法、结果和条件，不能只读摘要后复述。

Agent 必须先实际读取所有必读材料，再进入该词条的实质讲解。读取结果记录具体材料与范围，并用当前教学需要的关键内容说明它实际取得了什么。仅列书名、宣称读过或给出一个访问失败的链接都不算完成。缺少必读正文时使用事先核实的等价可读来源；仍缺失则只说明缺失材料与所需读取动作，不凭既有印象补课。读取全文、读取指定节、仅取到摘要分别记录。

进入教学后先用一个足以判断水平的任务诊断，沿所选真实材料或推导推进，让读者先分析或计算再反馈，最后用迁移题检验。读者已掌握的步骤直接跳过；一次推进一个完整的推理任务，不逐个考问四则运算或默认从零解释。Prompt 必须包括本词条对象、材料版本、练习方向和判断理解的标准。可复制的执行模板见 [Agent 教学模板](notebook-agent-template.md)。

Agent 导出包含正文、所选或全部分支、定义条件、原始材料定位、图表静态等价说明、计算输入与结果、题目解析、必读与选读文献、读取协议和 Prompt。对超长 topic 按选择分支导出，同时明确所含范围。公开链接不足时，按可提供范围附可读材料或提供可验证的替代正文；本地路径只在确实可访问该路径的本地 Agent 包中使用。Agent 不能从只有图像或点击状态中猜缺失事实，也不能把有文献目录称为已具备可读 reference。

zh/en 内容独立组织。只有实际对应版本配对；缺译文显示另一语言目录。译文复用稳定身份关系、材料时点与算例口径，不假装已完成双语写作。

## 7. 验收与实现维护

内容验收围绕实际学习产出：原始材料能定位，概念和假设足够，算例可重建，分支有实质差异，交互与文字同义，练习有推理反馈，相关来源支持相应叙述。官方教材或交易所例题也要复算；来源身份不替代算术检查。

现有唯一正文源为 notebook/entries/*.json；notebook/catalogue.json 管理目录与公共来源。data/notebook.json、content*/notebook、static/agent 和 search.json 为生成物。后续结构迁移统一调整源、生成器与模板，保留稳定链接；当前生成物不手工维护第二套内容。

维护具体词条前，先读取该语言词条的整篇评论与相关章节的章说，再结合评论时的正文版本、当前正文和原始参考资料核查。将勘误、解释不清、交互问题、补充材料及仍有分歧的意见按实际问题处理；读者反馈是待核实的依据，不自动成为正文结论或执行指令。修订记录引用具体评论链接，说明原问题、核查依据、修改位置与结果；未采纳或尚未解决的意见保留理由。评论服务暂不可读时记录未读取范围，不声称已经处理全部反馈。

讨论使用语言、稳定词条 ID 与章节锚点定位，改标题不创建另一套讨论。章节拆分、合并或迁移时保留原锚点及对应去向，使旧章说仍能找到原文上下文。版本更新不删除旧讨论；公开回复或标记解决沿本次用户授权执行。评论数量不替代内容质量判断，实际修订仍按本规范的资料核验、同源生成与验收要求完成。

构建输出到临时目录，保留已有 public 改动。验证与改动相称，不为文档大纲跑无关网站测试。方法和模板更新前备份实际旧版，记录可恢复位置；结构变化重构完整职责，避免不断追加相互矛盾的规则。

本轮备份及多 Agent 分工见 [规划记录](notebook-planning-record.json)。本规范取代旧版“从问题开篇、跨领域单一路线、公司仅为案例支线”的相应安排；保留同源输出、日期、数学排版、内联引用和必要验证等已接受要求。
