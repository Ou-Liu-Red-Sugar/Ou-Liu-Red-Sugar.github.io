# 主页中文写作接入

通用方法由个人 skill `chinese-writing` 维护，完整流程在该 skill 的 `references/workflow.md`。开始及上下文恢复时先全文读取 [用户写作要求](writing-requirements.md)，再读取当前安装的 skill 与相应阶段的方法。主页 notebook 的当前范围、文件和生成方式见 [写作与生产规范](notebook-authoring.md)。

## 内容与方法

| 工作 | 通用流程中的用途 | 本项目提供的输入 |
|---|---|---|
| 教材与技术词条 | 教材讲解、说明文章 | 当前题目、读者已有知识、需要解释的关系与必要材料 |
| 研究记录 | 研究报告 | 研究时点、事实与假设、计算和原始来源 |
| 导览和可查参考 | 说明、参考记录 | 实际目录、稳定ID、查询条件和来源 |
| 编辑与写作校准 | 局部修订、版本比较 | 前后文、用户原话与改稿、具体待解决问题 |

第0版到最终草图、取材到深挖的推进依据沿通用 workflow。现有数据、旧稿和案例只按当前需要采用。归档大纲的章节清单、旧生产批次与旧模型设置不再构成写作要求。

## 分工与审读

Chat 或子 Agent 可承担本篇的取材、草图、文字审读、专业审查、局部填充或阅读检验。分工与交接使用 skill 的 `references/chat-collaboration.md` 和 `assets/chat-handoff.md`，明确实际任务、版本、材料、预算及停止点。分发方法副本时注明正式入口和版本，保存在本篇生产记录中。

审读按 skill 的 `references/specialist-checks.md` 执行。文字与专业职责分别交给实际执行者，按稿件成熟度调用；文字首判只取得读者设定、实际稿件及前后文，专业审查取得已经进入本轮稿件的内容与依据。专业意见处理后由文字审读者定稿，并决定措辞、详略和显示精度；正文填充后仍由它连续通读收尾。

## 校准记录

历史用户样本保留在 [writing-benchmark.md](writing-benchmark.md)，阅读历史保留在 [writing-reading-notes.md](writing-reading-notes.md)。用户原话、用户认可、助手归纳和模型试读各保留真实身份，归档或方法更新不改变其认可状态。引用旧文章的训练如实记录材料暴露。
