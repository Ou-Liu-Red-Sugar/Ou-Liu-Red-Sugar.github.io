## 投资学笔记怎么写

这部分笔记是我借助 ChatGPT 和 Codex 编写的. 我确定主题、结构和写作要求，并提出修改意见. 正文主要由 ChatGPT 阅读资料、规划后起草，再交给独立会话审校；Codex 负责整合内容，核对引用与计算，以及网页、交互图表和 Agent 版本的实现.

写作从阅读资料开始. 每个主题先查教材、公开讲义和研究论文，再结合财报、合约条款、交易所规则等原始材料. 读过相关部分、确定大纲以后才开始写. 引用放在实际用到的位置，公司案例和会变化的数据、规则会注明材料期间与研究时间.

内容按主题组织，五个领域各有自己的阅读路线，公司资料单独收录. 主要面向有充分数学背景的高年级本科生到研究生，一篇学习词条通常安排为 10–20 分钟的阅读与练习. 我希望先把对象和整体结构交代清楚，再拿具体材料来拆解. 例如讲资产负债表，先介绍它的主要板块，再让读者选择行业，读一家代表性公司的真实报表. 讲金融工具，也要解释条款和资金安排为什么是这样，而不只是列定义与公式.

投资分析以业务模型为核心：企业怎样收费，依赖什么资源，竞争与行业变化怎样影响经营，利润和现金又怎样形成. 在此基础上展开不同经营情景，比较普通股股东可能得到什么，以及相应的 Risk-Reward. 合约、融资、交易成本和实际执行也属于分析的一部分.

HTML 让一些纸面上不方便的解释更容易展开：引用可以就地查看，行业案例可以切换，图表可以调整参数. 学习词条还附有教学 Prompt 和 Agent 版材料，带上正文、参考文献、图表说明与练习，要求 Agent 先读指定文献，再开始讲解.

评论和章说也会参与后续更新. 发现算错、引用不合适，或者哪一段读起来不明白，都欢迎指出来；补充材料和不同看法也很欢迎. 维护时会回到相关资料核查，再修改正文和配套内容.
