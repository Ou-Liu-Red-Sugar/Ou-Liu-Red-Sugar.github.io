租赁形成使用能力与未来付款义务. 使用权资产、租赁负债、未来未折现付款、期间费用和现金分别记录这项安排的不同侧面.

<a id="bf13-lease-structure"></a>
## 1. 租赁的资产、义务、费用与现金

<strong>使用权资产</strong>表示租期内使用底层资产的权利；<strong>租赁负债</strong>表示按规则纳入计量的付款义务. <strong>未来未折付款表</strong>按到期时间展示这些付款；<strong>期间费用</strong>记录本期服务消耗和相关融资成本；<strong>现金表</strong>记录本期实际付出的资金. 前两者是时点存量，后两者是期间量，而未来付款表跨越了多个尚未发生的期间. [^bf13-fasb]

按Topic 842，合同必须在一段期间内以对价换取对<strong>已识别资产</strong>使用的控制权；客户需能够取得该资产使用产生的几乎全部经济利益，并有权决定资产如何使用. 不控制已识别资产的云服务或外包合同不因按月付款而成为租赁. [^bf13-fasb]

美国租赁准则将使用权和义务列入资产负债表，并区分经营租赁与融资租赁. 融资租赁分别确认使用权摊销和利息费用，偿还本金通常列筹资现金流，利息列经营现金流；经营租赁一般按直线法确认单一租赁费用，现金列经营活动. 短期租赁豁免的政策选择及部分可变付款会使费用范围超出租赁负债的计量范围. [^bf13-fasb]

使用权随服务消耗、减值等变化；负债随利息计量、付款和合同变化而变化. 起点的预付租金、初始直接成本及租金优惠等还会调整使用权资产，因此后续两侧余额可以不同. 本文直接使用原附注给出的付款与负债连接.

### 零售分支练习

<strong>任务. </strong>恢复 2024 年的经营与融资租赁负债，并核对负债总额；再说明 2025 年付款到期表的哪个量可以直接和 2025 年负债对接.

<strong>解析. </strong>2024经营负债 $179+2,375=2,554$，融资负债 $147+1,351=1,498$，合计4,052. 2025到期付款减表列利息后得到2,668和1,479，分别与当年两类负债对应.

## 3. Salesforce租赁资产与期限结构

Salesforce FY2026截至2026-01-31，比较日为2025-01-31. 租赁涉及办公室、数据中心和设备；融资租赁资产包含在PP&E内，融资租赁负债列入相应流动及非流动其他负债. [^bf13-crm]

| 原行及中文 | 2026-01-31 | 2025-01-31 |
|---|---:|---:|
| <strong>Operating leases／经营租赁</strong> | | |
| Operating lease right-of-use assets／使用权资产 | 2,003 | 2,157 |
| Operating lease liabilities, current／流动负债 | 548 | 579 |
| Noncurrent operating lease liabilities／非流动负债 | 2,189 | 2,380 |
| Total operating lease liabilities／负债合计 | 2,737 | 2,959 |
| <strong>Finance leases／融资租赁</strong> | | |
| Computers, equipment and software／资产原值 | 1,427 | 1,520 |
| Accumulated depreciation／累计折旧 | (813) | (708) |
| Property and equipment, net／净额 | 614 | 812 |
| Accrued expenses and other liabilities／流动负债 | 275 | 337 |
| Other noncurrent liabilities／非流动负债 | 260 | 341 |
| Total finance lease liabilities／负债合计 | 535 | 678 |

单位：M 美元. 融资租赁资产净额为 $1,427-813=614$，负债为 $275+260=535$；两者分别沿摊销和偿付等关系变动.

未来到期付款为：

| 未来付款所属财年 | Operating leases／经营租赁 | Finance leases／融资租赁 |
|---|---|---|
| FY2027 | 615 | 289 |
| FY2028 | 571 | 120 |
| FY2029 | 493 | 76 |
| FY2030 | 338 | 58 |
| FY2031 | 268 | 26 |
| Thereafter | 790 | 0 |
| Total minimum lease payments／未折现付款合计 | 3,075 | 569 |
| Less: Imputed interest／减：利息 | (338) | (34) |
| Total／租赁负债 | 2,737 | 535 |

经营租赁 $3,075-338=2,737$，融资租赁 $569-34=535$，分别对应原表负债.

到期表中的经营租赁付款未扣未来转租收入，后者在未来五年约258 M 美元、之后约35 M 美元. 包含尚未开始租赁的承诺总额约4.4 B 美元，其中约3.8 B 美元与办公室及数据中心有关. 4.4 B的范围与精度均不同于到期表的3,075 M，无法据此取得精确的未开始租赁金额. [^bf13-crm]

FY2026经营租赁费用614，融资使用权摊销375、利息25；纳入负债计量的现金为经营租赁695、融资租赁利息25、本金367，合计1,087. 本金付款减少负债，使用权摊销分配资产成本，因而费用与付现沿不同关系变动. [^bf13-crm]

### 软件分支练习

<strong>任务. </strong>用 2025-01-31 比较列恢复融资租赁资产净额和负债，写出它们在合并表中的位置；再用 2026 到期表核回融资租赁负债.

<strong>解析. </strong>资产净额 $1,520-708=812$，包含在PP&E内；负债 $337+341=678$，分别包含在应计及其他流动负债、其他非流动负债内. 2026到期表 $569-34=535$ 与资产负债表分项 $275+260=535$ 相符.

## 5. 五类租赁信息的综合重建
