给主页编写投资学笔记时，我发现自己经常要充当 Agent 的语文老师. 有的句子单独看说得通，连起来却看不出前后关系；该解释的地方一带而过，已经说明的限制又在段尾重复. 我希望读者顺着文章理解一个概念，结果自己先要一遍遍解释这句话该接在哪里、这个条件该放在哪一句里.

起初，我给它设 Benchmarks，留下改稿示范，希望它在下一篇里照着做好. 换了主题以后，我仍得反复解释句子次序和前后衔接的问题. 后来，我把查找写作方法也交给了 Agent：让它检索中文写作资料，读过相关部分后再试写、修改，并把可以复用的办法整理成 skill.

我们用到的资料包括夏丏尊、叶圣陶的《七十二堂写作课》《文心》，以及吕叔湘、朱德熙的《语法修辞讲话》. 选材与详略、文章组织、复句和句群、词序与标点，都有可以落到具体改稿中的讨论. 我们把这些方法放进草图阶段，让 Agent 在展开正文之前，就先处理材料怎样组织、句子怎样接续；具体的阅读范围和采用方式保存在[文献记录](https://github.com/Ou-Liu-Red-Sugar/chinese-writing/blob/main/references/literature.md)中.

## 思想草图

最后敲定的写法很像画画：先用草图确定主要元素及其关系，再逐步补足细节. 写文章也先从第0层草图开始，想清楚要让读者建立哪些认识、这些认识之间有什么联系，以及用什么材料把它们体现出来. 这一层可以用流程图或表格，只要能说明思想怎样进入文章，就不急着把它们写成段落.

以本文为例，第0层可以先把内容和写法对应起来：用反复改稿的经历交代动机；用草图片段展示衔接句和标点怎样组织语言；用专项修订和方法保存说明怎样复用. 标点如何约束表达，仅凭概念不容易说清，所以本文把篇幅留给草图片段及其解释.

## 句子骨架

进入第1层，才开始具体安排章节与段落. 此时就要使用选材、详略和句子组织的方法，决定每段大致写什么、怎样接住前文，以及从哪里转入下一步. 衔接句要直接写出来，中间尚未展开的内容则放进已经安排好标点的句子骨架中. 例如，在一段从特例推广到一般情形的数学讲解里，可以先写成：

> 前面的例子只用了两个取值，现在把它推广到有限多个取值. 设〔变量及各个取值〕，并以〔各取值的概率〕作为权重，则〔这些取值的加权平均〕可以写为：〔公式〕.

虽然括号里的内容还没有写出，这段话的推进方式已经确定了. 前一句交代推广的范围，句号在这里结束转场；后一句用“设……，并……，则……”把对象、权重和加权平均连在一起，再用冒号引出相应公式. 填充时，Agent 要沿着这次设定的顺序补入内容，前后句的关系已经写在骨架里. 衔接句、关联词与标点共同约束后续表达，使句子的分合、推进和语气在这一层就有了安排.

这种草图还要继续修，直到段落、句序、承接、关键措辞和标点都定下来. 最终草图已经很接近正文，剩下的只是意思和句法位置都已确定的少量文字. 如果还留着“这里解释一下原因”这样整块的空缺，就要继续把原因及其与前后文的关系写进骨架.

## 专项修订

怎样把第1层修到这个程度，要看草图具体缺什么. 检查篇章与内容时，要看材料是否围绕中心、读者需要的解释是否充分，以及旁支是否写得过多；检查衔接时，则把段末和下一段的开头连起来读，看有没有未交代的对象或跳过的推理步骤. 到句子这一层，再看主语能否连续承接、条件和结果怎样相连，以及关联词与标点能否把层次分清. 每条意见都要落到草图中的某一处，说清读者会在哪里接不上、需要怎样修改.

我还把防御性措辞单独列出来检查. 限定语要看它实际增加了什么：成立条件、证据归属和真实的未知范围都应贴着相应判断写，空泛的谨慎表态可以删去. 比如，讨论单一产品时，“销量不变时，提价会增加收入”已经写明这条判断的条件，后面再接“仍需结合具体情况，不能一概而论”，就没有增加信息. 删去后面的提醒，前面的“销量不变”仍然保留.

这些检查可以交给 Chat 或其他 Agent 协助，但每次要给它当前草图和明确的问题. 负责整合文章的 Agent 取回意见后，要处理具体问题，并核对修改是否已经落在草图中；早期草图、原始意见和实际修订也要留下来，便于逐处对照. 改几轮由问题决定. 骨架检查完成后，再单独安排正文填充，按已经确定的意思和句法位置补齐局部文字.

## 复用与校准

Benchmarks 也因此有了更具体的用途：换一份材料，检查 Agent 能否保留必要条件并根据后文安排句序，再请另一位执行者只根据成稿回答理解题，查看文章是否提供了足够的解释. 发现问题以后，回到相应的草图阶段，修正那里的组织办法. 这样，一次改稿留下来的就包括这篇文章的修改，以及下一篇可以继续使用的方法.

这套方法已经整理在 [chinese-writing](https://github.com/Ou-Liu-Red-Sugar/chinese-writing) 仓库中，包含写作流程、专项方法、草图模板和公开题库. [《独立性与不相关》的写作记录](https://github.com/Ou-Liu-Red-Sugar/chinese-writing/tree/main/examples/independence-correlation)还保留了第0版和第1版草图、审读意见及后续修订，可以对照着看每条意见怎样改变骨架，以及正文怎样从最后的草图中填出来.
