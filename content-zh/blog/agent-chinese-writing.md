让 Agent 帮我写投资学笔记时，我经常得充当语文老师. 它能列出概念、公式和结论，却未必能把这些内容接成一篇好读的文章：上一句还在解释一个概念，下一句就用上了未曾交代的条件；有时只是想说谁做了什么，也要绕过一长串修饰语才能读到主要动作. 我得逐处修改，读者才不必替它补全这些联系.

我试过给它设评测题（Benchmarks），也留下了一些改稿示范，希望它能把这些改法用到后面的文章里. 但换了主题，同类问题仍会出现. 我希望它能根据新的材料，自己判断一篇文章该怎样展开，便让它去学习中文写作资料，把其中可复用的方法整理成 skill，供后续写作调用.

夏丏尊、叶圣陶的《文心》和《七十二堂写作课》讨论材料取舍、详略和文章组织，吕叔湘、朱德熙的《语法修辞讲话》则从具体句子入手辨析词序、句法与标点. 我们把读到的方法用到实际改稿中，再将采用的原则、适用的情形和修改示例保存下来. [文献记录](https://github.com/Ou-Liu-Red-Sugar/chinese-writing/blob/main/references/literature.md)列出了阅读范围和采用依据.

## 思想与取舍

画画时，草图先确定画面中有哪些元素，它们放在哪里、彼此是什么关系. 哪处需要细画、哪处只留几笔，也要服从画面想表达的内容. 我们把这套思路用在写作上：先安排读者要认识什么，用哪些材料帮助他理解，再逐步落实到句子. 读者先注意哪个对象，在哪个难点停留，带着什么认识进入下一段，都与这样的安排有关.

第0版草图负责思想及其体现方式. Agent 要写清本篇准备说明哪些事，各项认识怎样相接，以及用什么材料、例子或推导把它们讲明白. 流程图和表格都可以，只要能看出思想之间的关系和各自的表达办法；具体段落和句子留到下一版安排.

例如要解释错题比例，可以先给出两份练习记录：小林做了10题，错2题；小周做了40题，错6题. 读者很容易看出小周的错题数更多，但两人完成的题量也不同. 第0版要安排的，就是让读者从错题数转向各自完成的题数，再理解为什么要把错题数除以完成题数. 这项解释值得展开，读者已经会的除法可以略写.

## 句子与标点

进入第1版，Agent 才开始安排具体章节和段落. 它要写出实际的起句和衔接句，排好句序与标点，暂时用占位保留还没有展开的中间内容. 上面的例子可以继续排成这样：

> 小周的错题数更多，但两人完成的题数不同. 要看错题在各自完成的题中占多大一部分，我们把错题数除以完成题数，得到各自的错题比例：小林为〔2÷10的结果〕，小周为〔6÷40的结果〕. 按这个口径，小林的错题比例更高.

开头的“但”把注意从错题数引向完成题量，下一句先说明要比较什么，再引入除法和错题比例. 冒号引出两人的计算结果，句号结束计算，最后一句接着比较两个比例. 具体数值还可以留空，内容怎样推进、在哪里停顿，已经有了实际安排. 后续审读便能沿着这份骨架检查和修改.

在草图里写出实际句子，我们也能及早判断句式是否合适. 说明谁做什么时，我们尽量让读者早点读到主要动作. 比起“这些笔记需要由我逐处修改”，“我需要逐处修改这些笔记”更适合接着讲我的改稿经历；两句都说得通，后一种写法沿用了前文的“我”，也更直接. 是否保留被动或把对象放到前面，要看它在当前叙述中的作用.

连接词像齿轮，用得合适，读者就容易顺着前文往下读. 前后句已经靠内容、句序和共同话题接上，就不必再用“因此”“同时”“此外”逐句提示；需要转折、交代条件或说明推论时，则应写清关系. 停顿也跟着整句安排，普通连接词后不自动加逗号，完整分句和插入说明的边界仍然保留.

## 修订与复用

第1版写好后，我们把草图交给 Chat 或另一个 Agent 审读. 审读者沿实际前后句读下去，核对每一步是否已有足够的解释，再分别检查篇章详略、句子与标点、必要条件. 前后关系不清，有时要补一项理由，有时要调整材料的位置；只添一个“因此”，补不出缺少的内容. 研究报告中的来源、估算和成立条件也要留在对应判断旁，空泛的“仍需谨慎”则可以删去.

主持写作的 Agent 收到意见后，结合材料决定怎样修改，把改动落实到草图，再连读受影响的前后文. 后续版本都围绕这些实际问题修正，不预先规定修改几轮. 最终草图应当已经接近成稿：段落、句序、解释、例子的位置和标点都已确定，剩下的只是意思和语法位置明确的局部文字，一处可能只有几十个字. 我们再单独下达正文任务，让 Agent 在这些位置补齐内容，按已经确定的骨架成文.

我们用 Benchmarks 检查这些方法能否用于新材料. 作者用新材料试写，另一位执行者只读成稿回答理解题，说明某个结论为什么成立、依赖哪些条件. 如果读者找不到答题所需的解释，主持者就核对题目与正文；确有内容缺失或表达不清，再回到相应的草图中修改. 草图、原始意见和实际改稿一起保存，下一次遇到相近问题时就能对照使用.
